MADE WITH SLIDE STUDIO

こんなスライドがつくれます。

数式や文献、動きのある図を組み合わせた、研究発表の実例です。

FROM OUTLINE TO PRESENTATION

発表づくりの流れ。

話す内容を整理し、スライドにして、
見た目や伝え方を整えます。

  1. 01

    下書き

    結論と話す順番を整理します。

  2. 02

    スライド

    図や文章をスライドにします。

  3. 03

    調整

    配置・配色・図の見せ方を整えます。

PRESENT & SHARE

発表にも、配布にも。

仕上がったら、HTML または PDF に。
受け取る人に Slide Studio のインストールは不要です。

.html

動きごと、ひとつのファイルに。

図のアニメーションを含む単一 HTML。ブラウザで開いて、そのまま発表できます。上のスライドも、この形式です。

.pdf

同じスライドから、配布資料も。

各ページの最後の段階を PDF に。途中の段階も選んで追加できるので、説明に必要な場面を資料に残せます。

GET STARTED

まずは、
起動してみる。

自分の PC で動く、ローカルアプリ。
リポジトリを取得したら、コマンドひとつで起動。

Python 3.13+uv
uv のインストール方法
TERMINAL
# リポジトリを取得して、起動
$ git clone https://github.com/edoaki/slide-studio.git
$ cd slide-studio
$ uv run slide-studio
初回は必要なパッケージを自動で取得します。

  1. 1
    保管フォルダを選ぶ

    初回の画面で、原稿や図を保存する場所を選びます。

  2. 2
    書き出し用ブラウザを準備

    ［準備が必要］と表示されたら、Chromium を準備します。

  3. 3
    ［新しい発表］から、つくりはじめる

    AI を使う場合は、チャットから準備・ログインします。

初回のパッケージ取得・Chromium の準備にはネットワーク接続が必要です。

原稿も素材も、手元に。

自分のフォルダで管理

原稿は .qmd、下書きは memo.md、文献は BibTeX。初回に選んだフォルダへ保存します。

AI は必要なときだけ

手動の編集・書き出しに AI のログインは不要です。使う場合は Codex・Claude Code・Antigravity を選べます。

現在開発中のアプリです。最新の使い方や制約は GitHub の README を確認してください。
