MADE WITH SLIDE STUDIO

このスライドも、
Slide Studio で作りました。

数式・文献・段階的に動く図を含む研究発表です。クリックや矢印キーで進められます。書き出した単一の HTML ファイルを、ここに埋め込んでいます。

WHAT YOU CAN DO

書く・並べる・動かす。
ひとつの画面で。

01

Quarto を、さわって組み立てる。

原稿は Quarto 形式（.qmd）のまま、ブロックとして画面に並びます。横並びや囲み、ブロック同士の間隔はスライド上で直接つかんで調整でき、記法を覚えなくても思いどおりのレイアウトにできます。

  • ブロックをドラッグで移動・横に並べる
  • 余白や大きさは端のつまみで調整
  • Quarto 本体のインストールは不要
02

@ と書けば、引用が付く。

文献は BibTeX でまとめておき、本文に @kool2019 のように書くだけ。そのスライドの下に出典が入り、最後の参考文献ページにも自動で追加されます。番号の振り直しも要りません。

原稿…代表的なモデル @kool2019 を説明する。
スライド…代表的なモデル [5] を説明する。
下部[5] W. Kool, H. van Hoof, M. Welling. Attention, Learn to Solve Routing Problems! ICLR 2019.
03

動く図を、型から作る。

段階的に動く図のための JavaScript の部品を同梱しています。AI に図を頼むと、この部品をコピーして組み立てるので、一から書かせるより崩れにくく、動きもそろいます。図は発表中にクリックで一段ずつ進み、書き出した HTML でもそのまま動きます。

  • 図はトピックごとにまとまり、ほかの発表でも再利用できる
  • 右上の ①–⑦ は段階の数
04

実験結果を、フォルダごと渡す。

ログや CSV が入った実験結果のフォルダを、そのまま参考資料に入れておくだけ。AI が中身を読みに行き、必要な数字を拾って表やグラフにします。どのファイルを開けばいいか、一つずつ説明する必要はありません。

05

「このページを」と言わなくていい。

チャットの宛先は、いま開いているページ（選んでいる図）に自動で決まります。ほかのページを見ながら同じ所を直してほしいときは［固定］、発表全体なら［全体］に切り替えるだけ。

直したあとはアプリが検査し、別の AI が見た目と文章を確認します。気に入らなければ、送信ごとに元へ戻せます。

06

テーマで、全ページがそろう。

色・フォント・見出しの形はテーマにまとまっていて、切り替えると全ページが一度に変わります。本文の色、強調色、表の見出しなど、役割ごとに色を決めるので、ページによって配色がばらつきません。テーマの調整もチャットで頼めます。

ON YOUR MACHINE

手元で動いて、
手持ちの契約で使える。

ネットがなくても編集できる

チャット以外はすべて自分の PC の中で動きます。移動中や学会の会場でも、編集・書き出しが止まりません。

いつものサブスクで AI を使う

ChatGPT・Claude・Gemini の契約にログインして、その利用枠で動きます。API キーや追加の料金は要りません。

ファイルは、ふつうのファイル

原稿は .qmd、文献は .bib、図は HTML。選んだフォルダにそのまま保存され、ほかのエディタでも開けます。

HTML と PDF で届ける

動きごと単一の HTML に。受け取る人はブラウザで開くだけです。配布用の PDF には、途中の段階も選んで残せます。

HOW IT'S DIFFERENT

ほかのやり方と、何が違う？

スライドソフトの手軽さと、Quarto や LaTeX の書きやすさ。その間をねらっています。

項目Slide Studio一般的なスライドソフトQuarto・Beamer を直接書くAI のスライド生成サービス
レイアウトの調整画面で直接つかんで調整画面で直接コードを書いて、ビルドして確認作り直しを頼む
数式・文献の引用@key で自動。参考文献ページも自動手で書いて、番号も手で管理自動サービスによる
動く図HTML の図を段階的に標準のアニメーション自分で書く多くは静止画
AI への頼み方開いているページに直接。直した後は検査と確認製品による別のツールでまとめて生成が中心
AI の料金手持ちの契約（ChatGPT・Claude・Gemini）製品による—そのサービスの料金
オフライン編集できる製品によるできるできない
データの置き場所自分の PC製品による自分の PCクラウド

GET STARTED

コマンドひとつで、
起動する。

自分の PC で動くアプリです。リポジトリを取得したら、あとは uv run だけ。

Python 3.13+uv
uv のインストール方法
TERMINAL
# リポジトリを取得して、起動
$ git clone https://github.com/edoaki/slide-studio.git
$ cd slide-studio
$ uv run slide-studio

  1. 1
    保管フォルダを選ぶ

    原稿や図を保存する場所を選びます。

  2. 2
    書き出し用ブラウザを準備

    ［動作環境］から Chromium を準備します。

  3. 3
    ［新しい発表］から作りはじめる

    AI を使うときは、チャットからログインします。

初回のパッケージ取得と Chromium の準備にはネットワーク接続が必要です。開発中のアプリのため、最新の使い方は README を確認してください。
